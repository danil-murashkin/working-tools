## 🔧 Настройка обмена данными между Windows и Ubuntu в VirtualBox

### 1. Установите **VirtualBox Guest Additions** в Ubuntu

> Это необходимо и для clipboard, и для общих папок.

1. Запустите виртуальную машину с Ubuntu 20.04.
2. В меню VirtualBox:  
   **Устройства → Установить образ диска с дополнениями гостевой ОС...**
3. В терминале Ubuntu выполните:
   ```bash
   sudo apt update -y && \
   sudo apt install -y build-essential dkms linux-headers-$(uname -r)
   ```
4. Смонтируйте CD и запустите установку:
   ```bash
   sudo mkdir -p /media/cdrom && \
   sudo mount /dev/cdrom /media/cdrom && \
   cd /media/cdrom && \
   sudo ./VBoxLinuxAdditions.run
   ```
5. Перезагрузите систему:
   ```bash
   sudo reboot
   ```

---

### 2. Настройте **общий буфер обмена**

1. В окне VirtualBox (VM может быть запущена):
   **Устройства → Буфер обмена → Двунаправленный**
2. Убедитесь, что служба запущена (обычно стартует автоматически после входа в GUI):
   ```bash
   VBoxClient --clipboard
   ```
   > Если не работает — добавьте её в автозагрузку через «Startup Applications».

---

### 3. Настройте **общую папку**

#### На стороне VirtualBox (хост — Windows):

1. В меню VirtualBox (при выключенной или работающей VM):  
   **Устройства → Общие папки → Настроить общие папки...**
2. Нажмите значок папки с «+».
3. Укажите:
   - **Путь к папке**: например, `C:\SharedVM`
   - **Имя папки**: например, `shared` (это имя будет использоваться в гостевой ОС)
   - ✅ **Автомонтирование**
   - ✅ **Создать постоянную папку** (если нужно сохранить настройку)
4. Нажмите **OK**.

> 💡 Убедитесь, что папка `C:\SharedVM` существует на Windows.

#### На стороне Ubuntu (гость):

1. Добавьте своего пользователя в группу `vboxsf`, чтобы получить доступ к общей папке:
   ```bash
   sudo usermod -aG vboxsf $USER
   ```
   > Замените `$USER` на ваше имя пользователя, если нужно (например, `sudo usermod -aG vboxsf danil`).

2. **Выйдите из системы и заново войдите** (или перезагрузите VM), чтобы изменения группы вступили в силу.

3. После входа проверьте, что папка смонтирована:
   ```bash
   ls /media/sf_shared
   ```
   > Общие папки монтируются в `/media/sf_<имя_папки>`. В нашем примере — `/media/sf_shared`.

4. (Опционально) Чтобы не писать `sf_` каждый раз, можно создать символическую ссылку:
   ```bash
   ln -s /media/sf_shared ~/shared
   ```
