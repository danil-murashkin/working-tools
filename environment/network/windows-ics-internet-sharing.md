# 🌐 Раздача интернета с компьютера под Windows на встраиваемую плату через Ethernet

> **Цель**: Обеспечить доступ в интернет для встраиваемой платы (SBC или другого устройства с Ethernet), подключённой по кабелю к компьютеру с Windows, при условии, что этот компьютер уже имеет доступ в интернет (через Wi-Fi, Ethernet, 4G и т.д.).  
>
> **Требования к плате**:  
> - Наличие Ethernet-порта (встроенный или через USB-to-Ethernet),  
> - Поддержка DHCP-клиента (например, `udhcpc`, `dhcpcd`),  
> - Доступ к консоли (UART, HDMI+клавиатура, SSH и т.п.).

---

## 🔌 Шаг 1: Подключите плату к компьютеру

- Соедините плату и компьютер **Ethernet-кабелем**.  
- Современные устройства поддерживают Auto-MDI/MDIX — обычный патч-корд подойдёт.

---

## 🖥️ Шаг 2: Включите общий доступ к интернету (ICS)

1. Нажмите **Win + R**, введите `ncpa.cpl`, нажмите **Enter**.
2. В окне **Сетевые подключения** определите:
   - **Адаптер с интернетом** — Wi-Fi, основной Ethernet, мобильный хот-спот и т.д.,
   - **Локальный Ethernet-адаптер**, к которому подключена плата.
3. Кликните правой кнопкой по **адаптеру с интернетом** → **Свойства** → вкладка **Доступ**.
4. Установите галочку:  
   ✅ **Разрешить другим пользователям сети использовать подключение к Интернету этого компьютера**.
5. В списке выберите **именно тот Ethernet-адаптер, к которому подключена плата**.
6. Нажмите **ОК**.

> 💡 **Почему `192.168.137.1`?**  
> Этот IP автоматически назначается Windows при включении ICS — это поведение по умолчанию.  
> При необходимости подсеть можно изменить, но это требует отключения ICS и ручной настройки NAT и DHCP, что значительно сложнее. Для большинства задач рекомендуется использовать ICS «как есть».

> ❌ Не используйте виртуальные адаптеры (например, Microsoft KM-TEST Loopback), если подключение физическое.

---

## 🔄 Шаг 3: Получите IP на плате

При загрузке плата должна автоматически запросить IP по DHCP.  
Если этого не произошло — выполните вручную (в консоли платы):

```sh
ip link set eth0 up        # поднять интерфейс (если не активен)
udhcpc -i eth0             # для Buildroot
# или
dhcpcd eth0                # для систем с dhcpcd
```

> ⚠️ Имя интерфейса (`eth0`, `enp1s0` и т.п.) может отличаться — проверьте через `ip link`.

---

## 📋 Шаг 4: Проверка подключения

### Узнать IP-адрес платы:
```sh
ip addr show eth0 | awk '/inet / {print $2}' | cut -d'/' -f1
```
Пример вывода:
```
192.168.137.2
```

### Проверить связь с хост-компьютером:
```sh
ping -c 3 192.168.137.1
```

### Проверить доступ в интернет:
```sh
ping -c 3 8.8.8.8
```

Если пинг до `8.8.8.8` успешен — интернет работает!

---

## 🛠️ Полезные команды (на плате)

| Задача | Команда |
|-------|--------|
| Список интерфейсов | `ip link show` |
| Все IP-адреса | `ip addr show` |
| Поднять интерфейс | `ip link set eth0 up` |
| Запросить IP вручную | `udhcpc -i eth0` |
| Просмотр маршрута | `ip route show` |
